# Changelog

Release notes are generated from the Git history and published with each
GitHub release.

## v0.0.1

### Added

- Read-only Gmail search, message, thread, label, and attachment commands.
- Read-only Google Drive search, metadata, download, and export commands.
- Desktop OAuth login with macOS Keychain credential storage.
- JSON output for successful commands and structured errors for expected failures.
- Safe, bounded downloads that do not overwrite existing files by default.
- Setup documentation, engineering context, and an AI agent skill.
- MIT license and project-focused ignore rules.
